# NorthPlus-MD3

给 North+ 论坛换上 **Material Design 3** 界面的浏览器扩展（Manifest V3），顺带做了一堆体验优化。

## 功能

**外观**
- MD3 界面：一键开关，关闭即恢复论坛原版样式
- 配色：跟随系统 / 浅色 / 深色
- 种子色：7 个预设色或自定义取色，按 Material 3 tonal spot 规则生成整套配色
- 发帖页：编辑器工具栏与编辑区合成一张卡片，「所见即所得」编辑区和帖子预览页适配深色 / 种子色

**布局**
- 宽屏适配：消除两侧大面积留白，最大内容宽度可调（1000px ~ 全宽）
- 精简页头：隐藏大 Logo 横幅，导航栏吸顶
- 折叠版块公告：默认收起长公告，按版块记住展开状态
- 响应式布局，窄屏也能看

**阅读**
- 阅读排版：正文 16px、更舒适的行距
- 图片查看器：点击帖内大图全屏查看，`←` `→` 切换
- 购买后原地刷新：买完楼层内容留在当前位置

**效率**
- 悬浮工具栏：深浅色切换、宽屏、快速回复、回顶
- 整行点击：点帖子 / 版块所在行任意处即可进入
- 快速回复支持 `Ctrl/⌘ + Enter` 发送
- 更新检测：每 6 小时读取一次 `update` 分支上的 `version.json`，有新版时图标显示 `NEW` 角标，弹窗顶部给出下载入口；也可在弹窗底部手动「检查更新」

所有选项都在扩展弹窗里，改动即时生效。

## 键盘快捷键

| 按键 | 作用 |
| --- | --- |
| `J` / `K` | 下一项 / 上一项（楼层、帖子、版块） |
| `Enter` | 打开选中的帖子或版块 |
| `Shift + Enter` | 在新标签页打开 |
| `←` / `→` | 上一页 / 下一页 |
| `R` | 跳到快速回复 |
| `T` | 回到顶部 |
| `?` | 显示快捷键帮助 |
| `Esc` | 关闭弹层 |

## 安装

目前没有上架商店，需要手动加载：

1. 下载本仓库（`git clone` 或 Code → Download ZIP 后解压）
2. 打开 `chrome://extensions`（Edge 为 `edge://extensions`）
3. 打开右上角「开发者模式」
4. 点「加载已解压的扩展程序」，选择仓库根目录（包含 `manifest.json` 的那一层）
5. 打开论坛刷新页面即可，点工具栏里的扩展图标调整设置

更新时 `git pull` 后在扩展页点一下刷新按钮。

## 目录结构

```
manifest.json      扩展清单
icons/             图标
src/color.js       种子色 → MD3 配色生成（内容脚本与弹窗共用）
src/content.js     注入论坛页面的脚本（工具栏、快捷键、图片查看器等）
src/content.css    MD3 主题样式
src/background.js  后台定时检查更新
src/update.js      更新检测逻辑（后台与弹窗共用）
src/popup.*        设置弹窗
```

## 说明

- 只在 `north-plus.net` 及其子域名下运行，只申请了 `storage`（保存设置）和 `alarms`（定时检查更新）权限。除了读取 `update` 分支上的 `version.json`（raw.githubusercontent.com）检查新版本外不发出任何请求，不收集、不上传任何数据。
- 纯样式 / 前端增强，论坛改版后可能有部分样式失效，欢迎提 Issue 或 PR。
- 本项目与论坛官方无关。

## 发布新版本

1. 改 `manifest.json` 里的 `version`，提交并推送 `main`
2. 在 GitHub 上发布对应的 Release（tag 如 `v2.1.0`，附上打包好的 zip）
3. **最后**更新 `update` 分支的 `version.json`（`version` 和 `url`），已安装的用户会在 6 小时内收到提示

`update` 分支只放这一个文件，先发 Release 再改它，避免用户看到提示却下载不到。
